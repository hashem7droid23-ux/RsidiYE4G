# تطبيق يمن فورجي (Yemen 4G) - استعلام الرصيد والباقات

تطبيق مخصص لمستخدمي خدمة «يمن فورجي» بالجمهورية اليمنية، يتيح لك الاستعلام المباشر عن رصيد مودمك ومتابعة استهلاك الباقة الرسمية بكل سهولة وأمان.

**حقوق البرمجة والتصميم:** المهندس هاشم القديمي  
**البريد الإلكتروني:** hashem7droid23@gmail.com

---

## 📥 كيفية تنزيل وتثبيت التطبيق

1. انتقل إلى تبويب **Actions** في المستودع.
2. اختر أحدث عملية بناء ناجحة (Build Yemen 4G APK).
3. انزل إلى قسم **Artifacts** في أسفل الصفحة.
4. قم بتحميل الملف باسم **`yemen-4g-hashem-debug-apk`**.
5. فك الضغط وثبّت ملف `app-debug.apk` على هاتفك الأندرويد.

## 📱 مميزات وطريقة الاستخدام

### 1. الاستعلام المباشر عن الرصيد
- أدخل رقم هاتف شريحة المودم الخاصة بك (يبدأ بـ 10 أو 1).
- اضغط على **«فتح البوابة الرسمية والاستعلام الفوري»** للاتصال المباشر ببوابة المؤسسة العامة للاتصالات (`https://svc.ptc.gov.ye/4g/`).
- سيتم نقل الرقم تلقائياً إلى خانة الاستعلام في الموقع الرسمي، وما عليك سوى إدخال رمز التحقق المرئي (الكابتشا) الرسمي ليظهر لك رصيدك الفعلي بدقة وموثوقية 100%.

### 2. دليل الباقات وحاسبة التجديد
- استعراض كافة باقات يمن فورجي الرسمية (15، 35، 80، 150، 250، 400 جيجابايت).
- حاسبة ذكية توضح سعر الباقة + ضريبة الاتصالات والمبيعات (14%) والمبلغ الإجمالي المطلوب توفره في حسابك لتجديد الاشتراك.

### 3. لوحة تحكم وإعدادات راوتر المودم
- روابط سريعة ومباشرة بنقرة واحدة لفتح صفحات ضبط المودم:
  - مودمات ZTE: `192.168.0.1`
  - مودمات Huawei: `192.168.8.1`
  - مودمات Tozed / FiberHome: `192.168.1.1`
- عرض كلمات المرور الافتراضية ونصائح تقوية الإشارة والتقاط الترددات.

## 🔒 الخصوصية وأمان البيانات

- **حفظ محلي فقط:** الأرقام التي تضيفها في قائمة المودمات المحفوظة تُخزن فقط داخل ذاكرة هاتفك الخاصة لتسهيل الاستعلام لاحقاً، ولا تُرسل لأي طرف ثالث.
- **اتصال رسمي مشفر:** جميع عمليات الاستعلام تتم حصراً وبشكل مباشر مع خوادم المؤسسة العامة للاتصالات اليمنية الرسمية.
- **بدون أذونات زائدة:** لا يطلب التطبيق أي أذونات وصول غير ضرورية للكاميرا أو جهات الاتصال أو الملفات.
